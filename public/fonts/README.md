# Local Kodar fonts

Inter (variable, normal) and Instrument Serif (italic, 400) match KodarMonet Labs. These WOFF2 assets were retrieved from https://kodarmonet.vercel.app/inter.woff2 and https://kodarmonet.vercel.app/instrument-serif-italic.woff2. They are self-hosted to avoid external font requests.

Both fonts use the SIL Open Font License 1.1. See Inter-LICENSE.txt and InstrumentSerif-LICENSE.txt for the upstream licenses.
